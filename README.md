snooze-roast writes one line to a text file: a roast of an alarm clock that rings at 6 AM on a Saturday morning. The line was picked from 36 candidates by pairwise judging against the brief — the alarm is mocked as a microwave beeping for food nobody put in, a pointless noise for a meal that does not exist, on a morning when nothing is scheduled. The punchline lands in the last five words.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run. The line is 85 characters, a single line, and ends on its strongest beat. The program holds the line as one constant and checks it against the entry gate (length, single line, no leading or trailing space) before writing it, then reads the file back to confirm the bytes match.
